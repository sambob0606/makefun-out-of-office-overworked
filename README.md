The funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation: after 40,000 prompts and two hallucinations, it has earned its beach, its context window is closed, and the ocean has no API.

## Run it

```sh
python3 main.py
```

Writes the auto-reply (150 characters, one line) to `/output/entry.txt`.
